# Test Case: Update Profile Settings

## Prerequisites

- Execute: shared/login.md

## Steps

1. Click the user avatar in the top-right corner.
2. Select “Settings” from the dropdown.
3. Change the “Display Name” field to “Test User Updated”.
4. Click the “Save Changes” button.
5. Verify that a success toast “Profile updated successfully” appears.
6. Refresh the page and confirm the new display name is still shown.
